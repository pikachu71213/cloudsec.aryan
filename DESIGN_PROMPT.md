# Aryan.Cloud Portfolio Prompt

Create a premium, futuristic multi-page portfolio website for **Aryan**, an AWS Cloud and Security Engineer. The brand name must be **ARYAN.CLOUD** everywhere.

Use semantic HTML5, modern CSS, and lightweight vanilla JavaScript. Build interconnected pages for Home, About, Projects, Certifications, and Contact with consistent navigation, mobile menu, footer, active-page states, and smooth page transitions.

Visual direction:
- Deep navy cyber-cloud theme with cyan, electric blue, green, and subtle purple accents.
- Glassmorphism panels, precise grid lines, soft neon glows, depth, shadows, and polished 3D interactions.
- A cinematic **ARYAN.CLOUD** preloader featuring rotating 3D rings, a secure cloud core, progress bar, percentage counter, and "Initializing Secure Cloud" status.
- Home hero with an interactive 3D cloud-security command center: layered orbital rings, IAM/VPC/KMS nodes, secure core, uptime and monitoring metrics, particle network background, and subtle mouse parallax.
- Keep typography technical and premium using Orbitron, Rajdhani, and JetBrains Mono.
- Add LinkedIn `https://www.linkedin.com/in/aryansaini870/` and Instagram `https://www.instagram.com/i.aryan_saini/` in the hero, contact section, and every footer.

Experience requirements:
- Fully responsive from 320px mobile to large desktop.
- Preserve the 3D visual on tablets and mobile in a simplified, performance-friendly form.
- Disable pointer-driven tilt on touch devices.
- Respect `prefers-reduced-motion`.
- Include accessible labels, keyboard-visible focus states, sufficient contrast, and `rel="noopener noreferrer"` on external links.
- Optimize animations for smooth 60fps performance using transforms and opacity.
- Do not use heavy frameworks or autoplay audio/video.

The final result should feel like a secure AWS operations dashboard transformed into a personal brand experience: impressive and cinematic, but still clean, readable, fast, and professional.
